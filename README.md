# Калькулятор экономики группы

Локальный MVP для расчёта экономики одной учебной группы.

Калькулятор показывает:

- выручку от платящих учеников и прочую выручку;
- прямые расходы: педагог, аренда, переменные расходы и эквайринг;
- распределённую долю общих расходов по часам или выручке;
- прямой вклад, полную прибыль и две точки безубыточности;
- сравнение до трёх сценариев и матрицу «ученики × цена».

## Важно

Это демонстрационный локальный MVP. Данные вводятся в браузере и не отправляются на сервер. Сохранения, учётных записей, ролей и облачного хранилища в этой версии нет.

Калькулятор группы не заменяет сетевую управленческую модель клуба: в следующей версии потребуются филиалы, группы, загрузка залов, ФОТ и сводный P&L сети.

## Запуск

```bash
npm ci
npm run dev
```

Затем откройте адрес, который покажет Vite.

## Проверка

```bash
npm test
npm run typecheck
npm run build
```

Все расчёты проверяются автоматическими эталонными сценариями. Денежные значения внутри расчётного ядра хранятся в копейках.
